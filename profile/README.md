## 🚀 What It Is
SolidWorks for Windows is a parametric 3D design tool that professionals and hobbyists use to model real, manufacturable products. Everything is connected: sketches drive features, features build parts, parts form assemblies, and drawings update automatically. Whether you're a working engineer or exploring SolidWorks for Makers on a personal project, the same clear, sketch-to-solid workflow helps you go from concept to finished design.

## ✨ Key Features
> Everything you need to design in 3D, from a first sketch to a manufacturing-ready package.

- 📐 **Sketch-driven parts** — Define geometry with editable sketches and dimensions that update the whole model when you change them.
- 🧩 **Assembly modeling** — Bring components together with mates to check fit, motion, and clearance before you build anything.
- 📄 **Automatic drawings** — Generate dimensioned 2D drawings that stay linked to your 3D model and refresh as it changes.
- 🔍 **Design checks** — Inspect interference, mass, and dimensions so problems surface early instead of on the shop floor.
- 🔄 **File exchange** — Open and save common CAD and neutral formats to share work with schools, suppliers, and 3D printers.

## 🎯 First Steps
1. Open SolidWorks and create a new Part.
2. Sketch a profile on a plane and dimension it fully.
3. Extrude or revolve the sketch to make your first solid feature.
4. Combine parts into an Assembly and add mates to position them.
5. Produce a Drawing to document the design for making or printing.

## ❓ Questions
**Is SolidWorks free?**
SolidWorks is a paid product from Dassault Systèmes, not free software. You can try it with a free trial, and there are affordable routes for non-commercial use — the low-cost "SOLIDWORKS for Makers" license for hobbyists and discounted student options — but no free full commercial copy exists.

**Can hobbyists use SolidWorks at home?**
Yes. Beyond professional licenses, the "SOLIDWORKS for Makers" license gives hobbyists a low-cost way to use SolidWorks for personal, non-commercial projects on Windows.

**Which versions of Windows are supported?**
SolidWorks is a 64-bit Windows application. Current releases target modern 64-bit editions of Windows 10 and Windows 11; check your specific version's notes for the exact supported builds.
